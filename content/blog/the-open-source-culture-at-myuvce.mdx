From the very beginning, MyUVCE was built by students, for students. Over time, the platform has grown into a robust ecosystem—and the entire website has been open-source for quite a while now! 

Building in public and allowing the UVCE community to contribute is the only way to ensure this platform survives and thrives long after the current batches graduate.

<Callout type="info" title="What does Open Source mean?">
  Open source means the code that runs this website is publicly available on GitHub. Anyone can look at it, learn from it, and most importantly, suggest changes to improve it.
</Callout>

## How You Can Contribute

Whether you are a first-year student who has never written a line of code, or a final-year tech enthusiast, there is a place for you here.

### 1. Write Articles and Guides (No Coding Required!)
Have a great experience from a recent hackathon? Want to write a guide for the incoming batch? You can submit an article directly through GitHub in your browser. 

There is a comprehensive, beginner-friendly guide to help you get started:
**[Read the Article Writing Guide](/blog/article-writing-guide)**

### 2. Fix Bugs and Build Features
Want to improve the website, tweak a UI component, or fix a bug? Check out the repository at [github.com/mrmak419/myuvce](https://github.com/mrmak419/myuvce), look for open issues, and submit a Pull Request!

Everything you see on the MyUVCE website is open for contribution. The platform is built using modern web technologies to ensure it is blazing fast and reliable:
- **Next.js 15 (App Router)** & **Tailwind CSS**
- **Static MDX Architecture** (for lightning-fast article rendering)
- **The Wall of Fame:** One of the core features, which dynamically pulls data to showcase the incredible placements of the alumni and seniors.



## The MyUVCE Ecosystem

While the MyUVCE website handles articles, guides, the Wall of Fame, and campus updates, there is another crucial part of the digital ecosystem:

### MyUVCE Hub
All academic resources (like PYQs, scheme notes, and study materials) are crowd-sourced on the dedicated campus platform, **MyUVCE Hub**. 

You can download it or access it on the web:
- **Web App:** [hub.myuvce.in](https://hub.myuvce.in)
- **Android App:** [Download on Google Play Store](https://play.google.com/store/apps/details?id=in.myuvce.hub&device=phone&hl=en)

While the website is open source, MyUVCE Hub is not. However, anyone can still contribute! It allows students to upload study materials and notes directly from their phones. So, if you want to share academic resources, head over to MyUVCE Hub!
